FAQ

Questions? We’ve got answers.

Is Syfex free?

Yes. All core security and moderation features are completely free. Premium is optional and only adds extra tools & quality-of-life perks.

How do I set it up?

Invite the bot, run /setup, and follow the interactive prompts. You can fine-tune everything later with commands or the dashboard.

Will Syfex nuke my server by mistake?

No. All aggressive actions are behind your own thresholds and settings. You always stay in control of what Syfex is allowed to do.

Where do I get support?

Join the official support server (link below) or use the /support command in your guild.
